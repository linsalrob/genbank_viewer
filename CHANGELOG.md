# Changelog

All notable user-visible changes to genbank_viewer are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); the project does not yet claim a complete reconstruction of pre-changelog history.

## Unreleased

### Added

- Repository-wide user and developer reference documentation.
- Deterministic Playwright documentation screenshots and asset/reference validation.
- Hosted-application link to the canonical Read the Docs site.
- Local Rust API-documentation validation and Read the Docs publication workflow.

### Changed

- Documentation navigation now separates user tasks, installation, reference, architecture, development, and project information.
- Read the Docs configuration now builds the existing MkDocs site instead of referring to a nonexistent Sphinx configuration.

## 0.1.0

The repository contains a Git tag and GitHub release for `v0.1.0`; the release entry was published without downloadable assets. The current codebase includes local plain/gzip GenBank loading, multi-record selection, grouped feature tracks, feature inspection, all registered NCBI genetic codes, six-frame rendering, exact nucleotide and peptide search, Rust/WASM execution, and GitHub Pages deployment. Exact introduction dates for individual capabilities are not reconstructed here.
