# genbank_viewer documentation

genbank_viewer is a focused, local-first browser viewer for GenBank genomes. Start with [How to use genbank_viewer](how-to-use-genbank_viewer.md), then consult [GenBank support](genbank-support.md) and [translation](translation.md) for interpretation details.

Open the deployed application at **https://linsalrob.github.io/genbank_viewer/**.

Developers should read [installation](installation.md), [architecture](architecture.md), [coordinates](coordinate-system.md), and [testing](testing.md). Sequence contents stay in the browser; see [privacy and security](privacy-and-security.md).
