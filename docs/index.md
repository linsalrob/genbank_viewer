# Webtemis documentation

Webtemis is a focused, local-first browser viewer for GenBank genomes. Start with [How to use Webtemis](how-to-use-webtemis.md), then consult [GenBank support](genbank-support.md) and [translation](translation.md) for interpretation details.

Developers should read [installation](installation.md), [architecture](architecture.md), [coordinates](coordinate-system.md), and [testing](testing.md). Sequence contents stay in the browser; see [privacy and security](privacy-and-security.md).
