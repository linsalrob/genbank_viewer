# Accessibility

Controls have visible labels and focus indicators. Focus the Canvas and use arrows to pan, `+`/`-` to zoom, and `Home` for the complete genome. Strand is conveyed by arrow direction and text, not colour alone; stops use both colour and `*`; partial ends use dashed outlines.

The header **Documentation** link has an explicit accessible name, uses the same tab, retains the privacy message, and wraps with it on narrow screens without covering genome controls.

The Canvas has an accessible record/feature summary and a textual visible-range description. Its label identifies the active genetic code, states whether zoomed-out stop-bar tracks or zoomed-in nucleotide/amino-acid sequences are shown, and identifies whether the current search target is one signed peptide frame, the forward nucleotide lane, the reverse nucleotide lane, both lanes, or a detailed sequence row. Every frame and compact nucleotide lane has a visible text label; stop codons use a narrow vertical shape as well as colour. The legend beneath the Canvas explains both render modes. Search type, sequence input, Search, Clear, Previous, and Next have explicit accessible labels or visible names and are keyboard operable. Ctrl+Enter or Cmd+Enter submits the multiline query, results announce through a live status region, and the current row uses `aria-current`. The match uses a label, outline, and hatching rather than colour alone. Selection details and warnings are ordinary HTML. Contrast targets readable light/dark combinations, and reduced-motion preferences are respected.

Canvas graphics cannot expose every base as an accessibility-tree node without severe performance costs. The summary, coordinate controls, textual search result list, inspector, and qualifiers are the supported textual alternatives; richer tabular sequence export is future accessibility work.

Every annotation-group checkbox has a visible label, native checked state, keyboard operation, and focus outline. A text summary below the Canvas names the enabled groups and visible annotation count. The Canvas description states that strands are separated, broad regions sit behind gene tracks, and all six reading frames remain present. Shape, outline, dash, and thickness distinguish track groups in addition to colour.
