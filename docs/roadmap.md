# Roadmap

Likely future work includes more GenBank location semantics, circular origin-spanning features, renderer performance profiling for large genomes, richer Canvas textual alternatives, prebuilt signed desktop packages for major operating systems, published SHA-256 checksums, and a tested offline update strategy. A PWA would additionally require a manifest, complete service-worker caching (including WASM), and network-isolated startup tests.

Out of current scope are approximate or mismatch-tolerant sequence search, regular-expression search, Smith–Waterman, protein-domain search, annotation editing/export, GFF3, BAM/CRAM, BLAST, comparative tracks, circular-map visualisation, Tauri packaging, authentication, a backend, and remote sequence fetching. Each requires separate biological, privacy, and architecture review.
