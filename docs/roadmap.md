# Roadmap

Likely future work includes more GenBank location semantics, circular origin-spanning features, renderer performance profiling for large genomes, richer Canvas textual alternatives, and deployment documentation.

Out of current scope are annotation editing/export, GFF3, BAM/CRAM, BLAST, comparative tracks, circular-map visualisation, Tauri packaging, authentication, a backend, and remote sequence fetching. Each requires separate biological, privacy, and architecture review.
