# Changelog

The repository changelog is maintained in [CHANGELOG.md on GitHub](https://github.com/linsalrob/genbank_viewer/blob/main/CHANGELOG.md). It summarises user-visible capabilities and documentation changes without duplicating the detailed guides.

Publishing a GitHub release triggers Read the Docs version synchronisation and a documentation build for the tag, provided `RTD_API_TOKEN` and `RTD_PROJECT_SLUG` are configured. See [Release and deployment](release-and-deployment.md).
